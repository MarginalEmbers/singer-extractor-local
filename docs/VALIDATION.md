v0.1 完整后端 smoke test 使用 48 kHz、576137 个样本（约 12 秒）的合成音，
实际输出仍为 576137 个样本、48 kHz，处理耗时 13.18 秒。
该数字包含测试时的首轮推理开销，**不是歌曲性能基准，也不代表 RTX 5090 的速度**。

v0.2 浏览器验收使用 24 kHz、288017 个样本的自检音，实际使用 CUDA。
整曲导出的采样率、样本数保持一致；目标 + 残差与原音的最大绝对误差为
`3.73e-9`。浏览器下载 ZIP 与服务器生成 ZIP 的 SHA-256 一致。
这里验证的是实际模型调用和文件流程，不是目标歌手识别效果。
