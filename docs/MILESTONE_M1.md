# M1 · 双阶段分离试听节点 · 2026-11-14

用户对本地一首双人歌曲的试听反馈：“进步非常明显，我觉得可以作为一个节点保存一下成果”。
原歌曲、45 秒试听、完整候选音轨、实验脚本、版本锁定的来源归档/权重、运行依赖清单与 SHA-256
已另存本机的 M1 节点；这些包含用户歌曲的资料不进入 GitHub、安装包或公开发布附件。

## 保留的配置

- Mel-Band RoFormer：44.1 kHz 立体声，352800 样本分段，50% 重叠。
- UNMIXX：24 kHz 单声道，45 秒预览整段推理；全曲 60 秒分段、30 秒重叠。
- 根据重叠音频比较两种排列并接续，线性淡入淡出；无独立分段响度归一化。
- 版本与权重校验值见 `singer_extractor/two_stage_manifest.json`。
- 实验设备 RTX 5080，PyTorch 2.7.1+cu128；未在 RTX 5090 上实测。

## 已有证据及边界

UNMIXX 适配器对作者公开 7 秒示例与公开输出的两轨余弦相似度为 0.99999989 / 0.99999967。
三个公开独立人声组成的小型合成对照，使用真值最佳排列评分，六个目标方向均有正 SI-SDR 改善。
该检查只验证有限示例的分离能力，不验证程序能够识别谁是 A，也不是跨歌曲基准。

交替独唱/静音的已知来源测试发现：短分段重叠匹配仍可能在静音后换人。
长段上下文在该测试改善了连续性，因此当前采用 60/30 秒；仍不保证全曲身份一致。
一首 277.33 秒真实歌曲在原实验中两阶段约 47.3 秒，峰值显存约 6.28 GiB。
加载缓存、显卡占用和输入内容会改变耗时；不作为接收方机器速度保证。

用户认可的是本次主观试听的明显进步，没有逐段确认所有歌手身份、所有和声或音色保真。
保留原始实验报告里的未验证标记，并单独记录本次反馈，避免把一次试听变成全面验收。

后续 v0.5 把相同模型/配置接入桌面，候选人声由用户试听选择，再写入可编辑目标轨。
